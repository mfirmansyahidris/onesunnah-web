# Five-language hadith candidates

`hadeethenc-candidates.json` contains 100 **draft candidates** for English, Indonesian, Malay, Arabic, and Urdu. The official HadeethEnc spreadsheet releases used by the builder contain 147 IDs present in all five languages. The builder removes repeated Arabic titles, excludes some repeated variants and reports needing more context, prioritizes ten familiar daily-practice references, and fills the remaining slots with shorter complete hadith texts. Similar variants can still occur and require editorial deduplication. This is an editorial shortlist, not a scholarly authentication or publication decision.

Each candidate preserves the complete hadith text for every language, the Arabic text, language-specific HadeethEnc page and attribution, publisher, release version, and original spreadsheet transcript. All records have `status: Draft` and `reviewed: false`. Nothing is uploaded to Firestore automatically. Review the Arabic wording, authenticity grade, exact book and hadith number, all translations, and suitability for a daily reminder before publication. Do not present a shortened excerpt as a complete translation.

The five source releases are recorded per candidate under `references` and `provenance`. Before publishing or redistributing translations, follow [HadeethEnc's republication conditions](https://hadeethenc.com/en/home), including unchanged text, source attribution, release version, and updates. The source API is documented in the [official HadeethEnc API repository](https://github.com/islamhouse-dev/hadith-api).

To rebuild the shortlist from the cached official spreadsheets, install `openpyxl` and run `python tools/build_hadeethenc_candidates.py`. Add `--refresh` to download current releases. Compare new release versions and review content changes before replacing existing drafts. The administrator can import the JSON file in Settings; importing into Firestore requires an administrator account and a working database.

The initial familiar references include [intentions](https://hadeethenc.com/en/browse/hadith/4560), [speaking good or remaining silent](https://hadeethenc.com/en/browse/hadith/5437), [wishing good for others](https://hadeethenc.com/en/browse/hadith/4717), [good character](https://hadeethenc.com/en/browse/hadith/4308), and [fair dealing](https://hadeethenc.com/en/browse/hadith/3716).
