# Five-language hadith candidates

An expanded [1,000-candidate research catalog](collection-1000/README.md) was prepared on 2026-10-16 from freshly downloaded official releases. It contains 1,000 Arabic/English/Indonesian/Urdu candidates, of which only 147 have Malay source translations. The remaining 853 are explicitly incomplete; the 1,000 × five-language target is not met. The complete subset, missing-translation queue, raw source records, coverage report, and source hashes are kept separately. The original shortlist file was not overwritten. A subsequent [Android daily release selection](android-daily-1000/README.md) replaces three unsuitable daily candidates and has now been staged in Firestore: 900 new drafts plus the original 100 unchanged documents, all still Draft and unreviewed. Publication approval is pending.

The public reading page has a separate bundled reference in `src/featured-reading.json`: HadeethEnc 4717, with full unchanged Arabic, five translations, and five explanations extracted from these official releases. `tools/build_featured_reading.py` regenerates it without changing the 100 draft records. Attribution, release versions, and source transcripts are retained. The page prefers Firestore records only when they are published, reviewed, and contain Arabic, translations, and explanations in all five languages; otherwise it shows this attributed reference. The editor now includes a per-language explanation field.

`hadeethenc-candidates.json` contains 100 **draft candidates** for English, Indonesian, Malay, Arabic, and Urdu. The official HadeethEnc spreadsheet releases used by the builder contain 147 IDs present in all five languages. The builder removes repeated Arabic titles, excludes some repeated variants and reports needing more context, prioritizes ten familiar daily-practice references, and fills the remaining slots with shorter complete hadith texts. Similar variants can still occur and require editorial deduplication. This is an editorial shortlist, not a scholarly authentication or publication decision.

Each candidate preserves the complete hadith text for every language, the Arabic text, language-specific HadeethEnc page and attribution, publisher, release version, and original spreadsheet transcript. All records have `status: Draft` and `reviewed: false`. The 100 candidates were imported into `onesunnah-e3a1e` / `(default)` / `hadiths` on 2026-10-15. Review the Arabic wording, authenticity grade, exact book and hadith number, all translations, and suitability for a daily reminder before publication. Do not present a shortened excerpt as a complete translation.

The five source releases are recorded per candidate under `references` and `provenance`. Before publishing or redistributing translations, follow [HadeethEnc's republication conditions](https://hadeethenc.com/en/home), including unchanged text, source attribution, release version, and updates. The source API is documented in the [official HadeethEnc API repository](https://github.com/islamhouse-dev/hadith-api).

To rebuild the shortlist from the cached official spreadsheets, install `openpyxl` and run `python tools/build_hadeethenc_candidates.py`. Add `--refresh` to download current releases. Compare new release versions and review content changes before replacing existing drafts. The one-time Firestore importer is `python3 tools/import_hadeethenc_candidates.py`; it validates the dataset, performs a dry run by default, and requires `--commit` to write. It refuses to overwrite an existing collection. The administrator can also import JSON in Settings after signing in with a properly authorized account.

The initial familiar references include [intentions](https://hadeethenc.com/en/browse/hadith/4560), [speaking good or remaining silent](https://hadeethenc.com/en/browse/hadith/5437), [wishing good for others](https://hadeethenc.com/en/browse/hadith/4717), [good character](https://hadeethenc.com/en/browse/hadith/4308), and [fair dealing](https://hadeethenc.com/en/browse/hadith/3716).
